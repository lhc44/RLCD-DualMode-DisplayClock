# 使用指南：时钟、Wi-Fi 配网与 Windows 副屏

本固件将原有本地时钟功能与 USB 副屏功能整合在同一块 ESP32-S3-RLCD-4.2 上。面板一次只由一个功能写入：启动默认为时钟，切换后才显示 Windows 副屏。

## 1. 按键总览

| 操作 | 时钟模式中的行为 |
| --- | --- |
| BOOT 短按 | 切换到下一个已启用页面；在设置中确认当前项目。 |
| KEY 短按 | 进入设置；在设置中移动选择。 |
| KEY 长按 | 从设置二级页面返回一级；在一级退出设置。 |
| BOOT + KEY 同时长按 1.5 秒 | 在 `CLOCK`（时钟）和 `DISPLAY`（USB 副屏）之间切换。 |
| 按住 BOOT 后短按 PWR | 进入 ROM 下载模式，用于刷写固件。 |

闹钟或番茄钟提示音播放时，任意按键会先停止本次提示音；随后再执行正常按键操作。

## 2. 首次 Wi-Fi 配网

1. 正常启动设备，保持在 **CLOCK** 时钟模式。
2. KEY 短按进入设置；进入 **系统** 分类。
3. 找到 `离线模式 开`，用 BOOT 确认关闭。
4. 屏幕提示“再次确认进入配网”时，再按一次 BOOT 确认。
5. 设备开启配网热点；手机或电脑连接：
   - SSID：`WeatherClock-XXXX`（`XXXX` 为设备 MAC 后两字节）
   - 密码：`12345678`
6. 浏览器打开 [http://192.168.4.1/](http://192.168.4.1/)，填写 2.4 GHz Wi-Fi 的 SSID 与密码；可填写备用 Wi-Fi，按页面保存。
7. 等待设备关闭配网热点并连接家庭 Wi-Fi。启动页会显示连接状态；成功后自动同步网络时间，并可使用天气、一言、网络检测、OTA 等网络功能。

已保存的网络凭据会存入设备 NVS，之后正常启动会自动连接。

### 修改 Wi-Fi 或重新配网

进入 **设置 → 系统 → 恢复出厂设置**，按 BOOT 二次确认。设备清除已保存配置并自动开启配网热点；按上面的第 5 步继续。

## 3. 原有时钟功能

- BOOT 短按轮换已启用的时钟、天气、工作页等页面。
- 设置页中 KEY 用于移动，BOOT 用于确认，KEY 长按用于返回或退出。
- `设置 → 网络` 可手动执行“同步时间”“同步天气”“更新一言”；`设置 → 系统 → 网络检测`可查看本地 IP、公共 IP 和服务状态。
- 未配网或主动开启离线模式时，时钟和本地页面仍可使用；网络同步、天气及在线功能暂停。

## 4. Windows USB 副屏

1. 用 USB 连接 Windows，安装 `RLCD-Driver-Setup.exe` 后在 **设置 → 系统 → 显示** 中选择“扩展这些显示器”。
2. 将虚拟显示器设置为 **400 × 300、横向、100% 缩放**。
3. 在设备上按住 **BOOT + KEY 1.5 秒**，设备从时钟切换到副屏。
4. 将窗口拖至该虚拟显示器。再次长按 BOOT + KEY 会立即回到时钟。

副屏模式期间本地 LVGL 时钟不会写入面板；时钟模式期间 Windows 帧也不会写入面板。这是为避免两套画面互相覆盖。

画面模式可通过 `E:\weixue\rlcd-usb-display\final\RLCD-Control.exe` 切换；日常桌面推荐 `Clear` 或 `Light`，深色桌面可选 `Dark`，`Photo` 使用抖动灰阶，运动画面可能出现可见抖动或残影。

## 5. 常见检查

- Wi-Fi 热点未出现：确认已完成第 2 节第 3、4 步的两次 BOOT 确认，且设备正在时钟模式。
- Windows 看到新显示器但板子仍显示时钟：按住 BOOT + KEY 1.5 秒切入 `DISPLAY`。
- 板子进入下载模式：正常开机时不要按住 BOOT；下载模式仅使用“按住 BOOT，再按 PWR”的组合。

# Windows driver notices

`windows/driver/source/idd_xfz1986_usb_graphic/` contains an IDDCX/UMDF indirect-display driver based on the Microsoft indirect-display sample structure. Files retain their embedded copyright notices.

The bundled JPEG headers identify the Independent JPEG Group, Guido Vollbeding, Ken Murchison, libjpeg-turbo contributors and Google. The accompanying binary `lib/jpeg-static.lib` is retained solely because the Visual Studio driver project links against it. Its applicable third-party terms remain in force.

No personal signing certificate, private key, signed catalog or device-specific credentials are committed to this repository.
